Good to know

  • One evaluation runs at a time. Finished results are saved as they complete. A run in progress lives in the running server, so if the server restarts, start that version again.
  • Documents sent to a model. Generating test cases sends the text of your documents to generator_model (the judge model by default). Choose one you are comfortable sending them to.
  • Supported documents: PDF with selectable text, .docx, .txt and .md.
  • Judge versions. ragevalkit pins its LiteLLM dependency to a tested range, so installs stay on versions that have been checked.
  • The API. Everything the dashboard does is a call to /api/… on the same server; the interactive reference is at /api/docs.
