What each one does

OptionUse it to…
extra_metricsAdd scores such as ROUGE or a length check. Each function gets (expected_answer, generated_answer) and returns a number, shown next to the built-in scores. A metric that fails on a question is reported as a problem and the run goes on.
on_completeRun code once when a run ends, with the summary and the rows (None instead of a summary if the run failed). Post to Slack, fail a CI job, write to a database.
column_map, extra_columnsUse your own spreadsheet column names, and carry extra columns (such as difficulty) into every result.
session_id_fnChoose the session id sent for each chat, for example to replay a conversation against a stateful backend with a stable id.
conversational_typesRow types that skip context scoring and text metrics, besides non-rag.
run_keyword_recall, run_bm25, run_semantic_similaritySwitch the built-in text metrics on or off. The meaning score loads a small local model the first time, so turn it off on a machine with no internet.
