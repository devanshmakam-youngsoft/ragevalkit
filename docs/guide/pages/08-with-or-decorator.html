What each one records

Run the question “Can I get a refund?” through both and this is what the dashboard keeps:

Recorded for the stepwith blockDecorator
Step name and how long it tookyesyes
Material (the text the judge scores)what you assign to s.materialthe return value, when you write material=True
Sources (checked against expected_sources)what you assign to s.sourcesnot available: use a with block
Inputs of the stepnot recordedevery argument, by name
Output of the stepnot recordedthe return value
Coversany block, even part of a functionthe whole function

Which one should I use?

Use withFor retrieval, and for parts of functionsYou choose exactly what counts as material and sources, and you can wrap just a few lines.
Use a decoratorWhen a function is one clear stageInputs and output show up in the step details with no extra code, which helps when chasing a wrong answer.
Mix freelyOne pipeline can use bothA decorator on the model call, a with block on the search. They add up the same way.
